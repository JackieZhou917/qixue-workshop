# 登录鉴权
前端输入账号密码进行登录  -->  后端校验账号密码是否合法  -->  后端生成一个身份令牌  -->  向前端返回登录成功并将这个令牌给到前端  -->  前端本地保存token  -->  前端后续发其他请求时需要携带token给到后端

- token 应该具有时效性: 为了安全考虑，有效时间过长，丢失token后的危害越大

- 双token 实现用户无感刷新:
  1. 前端登录成功后，后端返回两个token，一个是access_token 和 refresh_token, 并本地保存
  2. 前端后续的请求都携带access_token
  3. 当access_token失效后，一旦前端再次发请求，后端会返回 416 状态码
  4. 前端读取本地 refresh_token, 并向后端发送请求，后端返回新的 access_token 和 refresh_token
  5. 重塑用户刚刚失败的请求

- JSON WEB TOKEN (JWT)
  一套标准的生成 TOKEN 的手段，其生成的token包含三部分:
    1. Header (头部)  存放诸如：加密类型、加密方法等
    2. Payload (负载)  存放诸如：签发时间、过期时间、账号相关信息等
    3. Signature (签名)  存放诸如：只有服务器才知道的信息(加盐)

# coze 工作流
coze是一个低代码平台，提供了两种方案创建工作流：
1. 提示词一键生成   (节点少，推荐)
2. 人工拖拽配置     (节点多，推荐)

- 项目中的工作流：
1. 上传 base64 格式的图片  -->  识别图片中的主要元素  -->  以文字 + 语音的形式进行返回
生成一条工作流，当用户上传一张 base64 格式的图片时，需要分析图片，提取图中主要元素并描述，不需要对环境、背景等场景进行描述，如果图中的内容有危险，请进行危险提示。最后返回一份文字描述和这份文字的语音资源，返回的数据格式如下:
{
  danger: '图中可能存在的对小朋友有害的危险元素'
  description: '图片的文字描述'，
  audioUrl: '文字的语音资源'
}

2. 拍照学单词:
生成一条工作流，当用户上传一张base64格式的图片时，需要分析图片中的主体内容，比如：一只手拿着一个手机，手机就是主体内容。返回主体内容的英文单词，和该单词的的音标，以及音标的音频，附加中文翻译和2个例句。返回的数据格式如下：
{
  word: 'dog',
  chinese: '狗',
  pronunciation: '/dɒɡ/(英)  /dɔːɡ/(美)',
  voice: '发音',
  examples: [
    'I have a dog.',
    'There is a lovely dog.'
  ]
}

3. 古诗词:
  1. github上开源的api(诗泉：https://poetry.palemoky.com)
  2. 诗泉的随机接口每次请求都会返回一首新的古诗词
  3. 希望用户一天之后看到的是同一首诗
    (1)前端缓存起来 -- IndexDB (客户端数据库)
    (2)后端缓存 -- map对象、Redis数据库
  4. 前端朝后端请求 -->  后端朝诗泉请求 -->  得到数据返回给前端的同时写入Redis  -->  未来一天内前端发送请求
    -->  后端读取Redis中的数据返回  -->  一旦过了凌晨00: 01前端再有请求  -->  后端朝诗泉请求

4. 为诗词配图:
为诗词配图 打造一条工作流，工作流的主要目的是为古诗词生成对应的配图和诗词赏析和诗词朗读音频，方便小朋友理解诗词意境。比如工作流接收的参数类型如下：{ title: '静夜思', content: [ "床前看月光，疑是地上霜。", "举头望山月，低头思故乡。" ], author: '李白', dynasty: '唐' }， 根据用户上传的参数内容，先创建诗词内容分析节点，将每一句诗词都处理成一段适合用于生成图片的prompt，根据你对内容的理解，将诗词按顺序分段。再根据生成的prompt来生成配图。配图的数量控制在4-10张之内。图片风格：卡通，适合12岁以内的小朋友学习。注意图片中不能出现非法内容，包含：色情，血腥，暴力，政治，以及其他不利于小朋友身心健康的元素。诗词解析控制在100字以内。

最终返回的数据格式为： { title: '诗词名'， imgArr: ['图片地址', '图片地址', '图片地址', ...], analysis: '诗词解析', voice: '诗词的语音朗读资源' }

优化对诗词分段之后的描述提示词，比如：“床前明月光”，应该是一幅李白站在房间内的窗前，透过窗口观望窗外的田园场景，月光狡黠，普照大地的场景图。“疑是地上霜”，窗外的大地被月光照射，植物，土地仿佛被盖上了一层寒霜的场景。按照这个思路优化生图的提示词

# Redis 缓存
1. 每日缓存: 今日推荐诗词缓存到Redis
2. 定时刷新: 每天凌晨00: 01刷新Redis缓存中的今日推荐诗词  (后端自动重新从诗泉获取新的诗词)
3. 手动刷新: 前端点击换一首按钮，后端不从缓存取数据
4. 分布式锁: 防止刷新频率过高带来的并发问题
